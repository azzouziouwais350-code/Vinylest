# dream.player

Lecteur de musique pixel dreamcore en un seul fichier HTML.
Importe tes mp3 (glisser-déposer, playlist, visualiseur) ou colle un lien Spotify.

## Utilisation
Ouvre `index.html` ou installe l'appli depuis ton navigateur (PWA).

## Fonctionnalités
- Import de fichiers audio locaux
- Lecteur Spotify intégré
- Visualiseur pixel, mode aléatoire, répétition
- Mode hors-ligne

## Limites
- Spotify nécessite une connexion internet
- Les mp3 importés ne sont pas conservés à la fermeture
